# Atlas UI Guidelines

> Atlas should feel like a premium SaaS product, not a traditional
> monitoring dashboard.

## Inspiration

-   Linear
-   Vercel
-   Railway
-   Arc Browser
-   Raycast
-   Stripe Dashboard
-   Tailscale
-   OrbStack

Avoid: - Grafana - Kibana - AdminLTE - Bootstrap Admin - Flowbite
templates

## Product Motto

**Observe Everything. Control Nothing.**

## Design Principles

-   Premium dark theme
-   Large typography
-   Spacious layouts
-   Smooth animations
-   Minimal but information rich
-   No generic admin template

## Primary Navigation

-   Fleet
-   Nodes
-   Services
-   Containers
-   Processes
-   Alerts
-   Events
-   Logs
-   Maps
-   Reports
-   Costs
-   Settings

## Node Workspace

Fleet └── Server ├── Overview ├── Containers ├── Services ├── Processes
├── Logs ├── Events ├── Dependencies ├── Agent └── Settings

## Color Palette

Background: #09090B Surface: #111318 Hover: #171A21 Border: #262B35
Primary: #6C5CE7 Success: #22C55E Warning: #F59E0B Danger: #EF4444 Info:
#3B82F6

## Typography

Hero: 48px Page Title: 32px Section: 24px Card Title: 18px Metric: 52px
Label: 13px

## Every Page Should Have

1.  Hero section
2.  KPI summary
3.  Primary visualization
4.  Detailed table/list
5.  Secondary insights
6.  Actionable recommendations where appropriate

## Core Pages

Fleet, Nodes, Node Overview, Services, Containers, Processes, Alerts,
Events, Logs, Maps, Reports, Costs, Settings.

## Costs Page

Show: - Monthly spend - Daily spend - Projected spend - Cost by
provider - Cost by region - Cost by environment - Cost by service - Cost
by team - Server cost breakdown - Resource efficiency - Cost
optimization recommendations

## Charts

-   Thin lines
-   Rounded tooltips
-   Minimal grid
-   Smooth animations

## Tables

-   Sticky headers
-   Search
-   Filters
-   Pagination
-   Hover highlight

## Responsive

Desktop first. Support desktop, tablet and mobile.

## UI Checklist

-   Premium typography
-   Excellent spacing
-   Responsive
-   Accessible
-   Consistent design language
-   No generic admin dashboard appearance

## Final Rule

Every screen must answer: - What happened? - Where? - Why? - What's the
impact? - What should the operator do next?
